# Week 4 Mini ML Project Explanation

## Dataset
The project uses the Iris dataset from scikit-learn. The input features describe flower measurements and the target represents the flower class.

## Train and Test Split
The dataset is divided into training and testing data. The model learns from the training data and is evaluated using the testing data.

## Feature Scaling
StandardScaler is used to scale the feature values before training the KNN model.

## Model
K-Nearest Neighbors (KNN) is used as the classification model with 5 neighbors.

## Prediction
After training, the model predicts the flower classes for the test data.

## Evaluation
Accuracy shows the overall percentage of correct predictions. The confusion matrix shows how the predicted classes compare with the actual classes. The classification report gives precision, recall, and F1-score.

## Summary
This mini project follows a basic machine-learning workflow: load data, split data, scale features, train a model, make predictions, and evaluate the results.
