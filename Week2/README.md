# Week 2 - NumPy and Pandas

This week covers NumPy fundamentals, pandas data manipulation, data cleaning, basic analysis, and Git workflow practice.

## Days

- Day 1: NumPy arrays, indexing, slicing, and array math
- Day 2: Reshape, flatten, random arrays, statistics, and matrix operations
- Day 3: Pandas Series, DataFrames, CSV inspection, and column selection
- Day 4: Missing values, sorting, renaming, calculated columns, and groupby
- Day 5: Mini dataset project, summary notebook, and Git cleanup
