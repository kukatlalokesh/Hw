# Week 2 Git Summary

## Git Commands Used

```bash
git status
git add .
git commit -m "Add Week 2 NumPy and pandas exercises"
git push origin main
```

## Week 2 Learnings

- NumPy arrays support fast numerical operations.
- Array shape, size, and dimensions describe array structure.
- Indexing and slicing provide access to specific array elements.
- Reshape changes an array's dimensions without changing its data.
- Flatten converts an array into one dimension.
- NumPy can generate random values and calculate statistics.
- Pandas Series represent one-dimensional labeled data.
- DataFrames represent tabular data with rows and columns.
- pandas provides tools for reading CSV files, cleaning missing values, sorting, filtering, creating columns, and grouping data.
- Git is used to track changes and push completed work to GitHub.
