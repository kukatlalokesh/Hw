# Week 1 Learning Summary

Week 1 covered the core Python programming concepts needed for beginner-level problem solving.

- **Day 1:** Variables, data types, input/output, if-else, loops, and functions.
- **Day 2:** Lists, manual max/min logic, sum and average calculations, and multiplication tables.
- **Day 3:** String operations, palindrome logic, word counting, and dictionary-based character frequency.
- **Day 4:** Reusable functions, prime checking, Fibonacci series, and nested-loop patterns.
- **Day 5:** Safe file handling, student marks and grading, combined practice problems, and Git organization.

The main goal was to practice writing clean Python programs while strengthening loops, functions, collections, strings, and basic problem-solving skills.
