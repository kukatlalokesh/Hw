# Week 1 Git Summary

## What I Learned

### Day 1 - Python Basics
- Variables and data types
- Input and output
- Conditional statements
- Loops
- Functions
- Basic calculator and number classification logic

### Day 2 - Lists and Loops
- List operations such as append, insert, remove, sort, and reverse
- Finding largest and smallest values without built-in functions
- Calculating sums and averages with functions
- Generating multiplication tables

### Day 3 - Strings and Dictionaries
- String length, case conversion, reversing, and vowel counting
- Palindrome checking with manual loops
- Word counting and word-length calculations
- Character frequency using dictionaries

### Day 4 - Functions and Loop Logic
- Creating reusable functions
- Square, cube, factorial, and simple interest calculations
- Prime number checking
- Fibonacci series generation
- Nested loops and star-pattern printing

### Day 5 - Files and Practice
- Safe file handling with `with open(...)`
- Writing, appending, and reading text files
- Working with dictionaries to store student marks
- Calculating averages and grades
- Combining concepts from earlier days in mini problems

## Week 1 Takeaway

Week 1 focused on building a strong Python foundation through hands-on practice with variables, conditions, loops, functions, lists, strings, dictionaries, file handling, and basic problem solving. The exercises also reinforced writing readable and reusable Python code.
